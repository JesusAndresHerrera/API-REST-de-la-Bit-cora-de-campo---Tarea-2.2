# Diagramas y capturas

Estas son las imágenes utilizadas en la documentación del Grupo 04. Los diagramas se guardan en PNG y SVG; el SVG permite cambiar textos, cajas y flechas. Las capturas de Swagger y Postman se tomaron el 6 de noviembre de 2026 durante las pruebas locales.

El Runner muestra una ejecución completa. Las capturas individuales de creación y validación se tomaron después para mostrar sus respuestas con mayor detalle; no representan una segunda ejecución completa. El registro utilizado para esas capturas también se eliminó al terminar.

La captura de creación muestra el registro de prueba con ID 4. La fecha JSON está en UTC; la fecha de las pruebas se expresa en hora de Honduras.
